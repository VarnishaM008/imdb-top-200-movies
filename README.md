# IMDb Top 200 Movies Data Extraction

## 📌 Project Description

This project extracts and analyzes IMDb movie data using IMDb's official public datasets. It identifies the top 200 movies based on average rating and number of votes, and stores the results in both CSV and Excel formats.

The project demonstrates how Python and Pandas can be used to download, process, filter, sort, and export large datasets.

## 🎯 Objective

The main objectives of this project are:

* To collect movie data from IMDb's official datasets.
* To filter only movie titles.
* To combine movie information with rating information.
* To identify the top 200 movies based on rating and votes.
* To store the processed data in CSV and Excel formats.
* To display the final results in a structured format.

## 📊 Data Source

The project uses IMDb's official public datasets:

* `title.ratings.tsv.gz` – Contains movie ratings and vote counts.
* `title.basics.tsv.gz` – Contains movie titles, title types, and release years.

IMDb Dataset:
https://datasets.imdbws.com/

## ⚙️ How the Project Works

The program follows these steps:

1. Downloads IMDb ratings data.
2. Downloads IMDb movie basics data.
3. Filters the dataset to include only titles with `titleType = movie`.
4. Selects the required movie information.
5. Selects rating and vote information.
6. Merges both datasets using the IMDb title ID (`tconst`).
7. Removes records with missing required values.
8. Sorts movies by:

   * Average Rating
   * Number of Votes
9. Selects the top 200 movies.
10. Adds rank and timestamp information.
11. Saves the final data as CSV and Excel files.
12. Displays the results in the terminal.


## 📌 Important Note

This project uses IMDb's official public datasets rather than directly scraping the IMDb website.

The ranking generated by this program is based on **average rating and number of votes** and may differ from IMDb's official Top 250 ranking because IMDb uses its own weighted-rating methodology.
